# 🐒 쌀숭이 봇 (MapleStory Discord Bot)

메이플스토리 유저들을 위한 디스코드 고정 파티 관리 및 일정 조율 자동화 봇입니다.
파티원들의 투표를 통해 공통된 시간을 찾아주고, 레이드 이후의 수익금 분배와 경매장 수수료 계산까지 한 번에 해결해 줍니다.

## ✨ 주요 기능

* **넥슨 Open API 연동**: 본인의 캐릭터 정보를 등록하여 파티 관리에 활용합니다.
* **고정팟 관리 시스템**: UI를 통한 손쉬운 파티 생성, 목록 확인, 삭제 및 멤버 관리를 지원합니다.
* **일정 투표 자동화**: 
  * 매주 목요일 오전 10시, 파티원들에게 자동으로 일정 조율 DM을 발송합니다.
  * 파티원들의 투표 결과를 분석하여 모두가 가능한 시간(교집합)을 지정된 공지 채널에 요약해 줍니다.
* **수익금 정산 (분배 계산기)**: 보스 처치 수익금을 인원수에 맞게 1/N 균등 분배하거나, 퍼센트(%) 비율로 차등 분배할 수 있습니다.
* **경매장 대금 청구 (수수료 계산기)**: 지인과 거래할 때 경매장 수수료(MVP 3% 또는 일반 5%)를 고려하여 원금을 1메소의 오차 없이 받을 수 있는 정확한 등록 금액을 계산해 줍니다.

## 🛠️ 설치 및 실행 방법

본 프로젝트는 Python 3.8 이상의 환경을 권장합니다. 클라우드 서버(Ubuntu 등)에 24시간 무중단으로 배포하는 것을 추천합니다.

### 1. 저장소 클론 (Clone)

    git clone https://github.com/본인아이디/본인저장소이름.git
    cd 본인저장소이름

### 2. 가상 환경 설정 및 패키지 설치

    # 가상 환경 생성 및 활성화 (Linux/Mac 기준)
    python3 -m venv venv
    source venv/bin/activate
    
    # 필수 패키지 설치
    pip install discord.py python-dotenv aiohttp

*(또는 pip install -r requirements.txt 명령어를 통해 필요한 패키지를 한 번에 설치할 수 있습니다.)*

### 3. 환경 변수 (.env) 설정
프로젝트 최상위 디렉토리에 .env 파일을 생성하고 발급받은 디스코드 봇 토큰을 입력합니다.

    DISCORD_TOKEN=여기에_디스코드_봇_토큰_입력

### 4. 봇 실행

    python main.py

> **Tip:** 백그라운드에서 24시간 실행하려면 서버 터미널에서 tmux를 활용하세요.

## 📝 명령어 가이드

* `/api등록 [넥슨오픈API키]` : 넥슨 API 키 등록
* `/캐릭터등록` : 파티에 사용할 캐릭터 등록
* `/고정팟생성` : 고정 파티 생성 및 멤버 초대
* `/고정팟채널지정` : 투표 결과가 요약될 서버 공지 채널 세팅
* `/고정팟투표` : 수동 일정 재투표 진행
* `/분배 [금액] [인원] [배율(선택)]` : 1/N 또는 퍼센트 차등 정산
* `/대금청구 [원금]` : 경매장 수수료(MVP 3% 기본, 숫자 뒤에 x 입력 시 5% 적용) 역산
